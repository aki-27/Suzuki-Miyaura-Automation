# Analysis scripts

This directory contains analysis notebooks and scripts that support the Suzuki-Miyaura autonomous optimization study.

- `4samples_average/`: analysis of four-sample batch averages during the optimization campaign.
- `comparison_models/`: descriptor and model-comparison notebooks and logs.
- `screening_aquisition_func/`: acquisition-function and batch-size screening outputs.
- `shap/`: reproducible Gaussian-process regression, SHAP, and permutation-feature-importance analysis.
- `variance/`: uncertainty and variance-related notebook analysis.
