# Confirmed historical PHYSBO version

The authors confirmed with co-author Tamura, a NIMS-OS developer, that **PHYSBO 2.0.0** was used for the 2024 main campaign through **NIMS-OS 1.0.1**. They also confirmed use of standard implementations without manual hyperparameter adjustment. This author confirmation supersedes the earlier inference from package release dates.

NIMS-OS 1.0.1's dependency metadata does not pin PHYSBO to an exact version, so that metadata alone cannot establish the installed version. The version is not assigned to the December 2023 preliminary campaign. Complete historical build dependencies and per-iteration learned states remain unavailable in this repository; exact executable replay is not claimed.

See [STANDARD_SETTINGS.md](STANDARD_SETTINGS.md) for version-specific automatic learning and wrapper settings, and [the experimental record](../../../docs/EXPERIMENTAL_RECORD.md) for the full scope of author-confirmed corrections.
